This repository has been created as part of my journey into Git and GitHub. It is a simple demonstration project where I am learning the fundamentals of version control, repository management, and collaborative software development.

About This Repository

The purpose of this repository is to understand how Git works and to practice essential Git commands and concepts. Through this project, I am learning how to:

Create and initialize a Git repository
Track changes made to files
Add files to the staging area
Create meaningful commits
View the history of changes
Work with branches
Connect a local repository to GitHub
Push and manage code on a remote repository
Understand the basic workflow used in software development

Although this is a beginner-level project, it represents an important first step toward becoming more comfortable with Git, GitHub, and software development workflows.
